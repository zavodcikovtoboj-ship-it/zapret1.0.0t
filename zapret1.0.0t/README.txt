# 🛡️ zapret1.0.0t

**zapret1.0.0t — инструмент для обхода сетевых ограничений и управления сетевыми сценариями в Windows.**

Проект предназначен для Windows 10/11 и использует BAT-сценарии для запуска различных режимов работы.

## ✨ Возможности

- 🚀 Несколько режимов запуска.
- ⚙️ Различные варианты General.
- 🌐 Поддержка Fake TLS.
- 🔧 Дополнительные настройки через BAT-файлы.
- 📂 Собственные списки и конфигурации.
- 🖥️ Работа в Windows.
- 🔄 Управление сетевыми сценариями через командные файлы.

## 🖥️ Системные требования

- Windows 10
- Windows 11
- Архитектура x64
- Права администратора для сценариев, которым необходим доступ к сетевым драйверам

## 🚀 Запуск

1. Скачайте архив проекта.
2. Распакуйте его полностью в отдельную папку.
3. Запустите нужный BAT-файл.
4. При необходимости предоставьте права администратора.
5. Следуйте инструкциям в командной строке.

## ⚙️ Режимы работы

| Режим         | Назначение              |
| ------------- | ----------------------- |
| General       | Основной сценарий       |
| General ALT   | Альтернативные варианты |
| Fake TLS AUTO | Варианты с Fake TLS     |
| Simple Fake   | Упрощённые варианты     |
| Service       | Управление службой      |
